# OROSWAP TESTNET BOT

Bot otomatis untuk swap token di jaringan testnet ZigChain.

## 🚀 Cara Menjalankan

1. Clone repo ini:
   ```
   git clone https://github.com/redixcommunity/OROSWAP-BOT.git
   cd OROSWAP-BOT
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Buat file `.env` berdasarkan `.env.example` dan isi:
   ```
   MNEMONIC=...
   RPC=https://testnet-rpc.zigchain.com
   CHAIN_ID=zig-test-2
   ```

4. Jalankan:
   ```
   npm start
   ```

## ⚠️ Peringatan

- Hanya untuk testnet.
- Jangan gunakan mnemonic wallet utama.
